# 비밀번호 재설정 이메일 — 개발자 전달용

- 제목: `subject.txt`
- HTML 본문: `password-reset.html`
- 일반 텍스트 본문: `password-reset.txt`
- 시각 확인용: `preview.html` (예시 코드가 들어 있으므로 발송에 사용하지 않음)

발송 서비스의 subject / html / text 필드에 각각 넣습니다. `{{...}}`는 치환 위치를 뜻하며 특정 발송 서비스의 문법을 전제로 하지 않습니다. 서버에서 치환하거나 해당 서비스의 변수 문법으로 바꾸세요.

## 변수

| 변수 | 값 |
|---|---|
| `service_name` | 실제 서비스명 |
| `verification_code` | 서버에서 발급한 6자리 숫자 문자열. `012345`처럼 앞자리 0을 보존 |

HTML에 넣는 서비스명은 HTML 이스케이프하세요. 코드 값은 `^[0-9]{6}$`로 검증하세요. 제목에 넣는 값에는 줄바꿈을 허용하지 마세요. 예시 코드를 실제 발송에 사용하지 마세요.

## 로고

공식 로고가 제공되지 않아 기본 HTML은 서비스명을 텍스트 워드마크로 표시합니다. 이미지가 차단돼도 서비스명을 읽을 수 있습니다. 공식 이미지 로고를 사용하려면 HTML의 `Text wordmark` 주석 아래 문단을 다음으로 교체하세요.

```html
<img src="{{logo_url}}" alt="{{service_name}}" width="120" style="display:block;width:120px;max-width:100%;height:auto;border:0;">
```

`logo_url`에는 외부에서 로그인 없이 접근 가능한 실제 HTTPS PNG 이미지 주소를 넣으세요. 이미지 비율에 맞춰 너비를 조정하세요. 로컬 파일 경로는 발송용으로 사용할 수 없습니다.

## 구현 범위

표 기반 레이아웃, 인라인 스타일, 시스템 글꼴, Outlook용 고정 너비 조건부 마크업을 사용했습니다. 코드가 실제 텍스트이므로 복사할 수 있습니다. JavaScript, 웹폰트, 재설정 링크는 없습니다.

코드 발급·유효기간·재전송·검증은 서버/앱에서 처리합니다. 유효기간은 정해진 값이 없어 본문에 넣지 않았습니다. 추가한다면 서버의 실제 정책과 일치시켜 주세요.

이 템플릿은 발송 서비스와 연결하거나 실제 이메일을 발송하지 않았습니다. 적용 후 사용하는 이메일 클라이언트에서 테스트 메일로 확인하세요.
